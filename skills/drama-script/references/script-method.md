# 剧本：方法

学习来源：shuohao-skills `novel-script`（Apache-2.0）的写戏规则（时长预算、常见动作、冷开场、修改纪律、常见病）；按本仓契约重写。

## 节拍

| type | 写什么 | 时长 |
| --- | --- | --- |
| `action` | 一拍一件事，叙述体，看得见的画面 | 默认 2 秒，可写 `seconds` |
| `dialogue` | 一句台词，`characterId` 是说话人，必须在本场 `characters` 里 | 字数 ÷ 4.5 |
| `voiceover` | 旁白或心声，`characterId` 可选 | 字数 ÷ 4.5 |

`emotion` 写表演层的信息（「嘴上让座，身子没动」）。潜台词放这里，不要在台词里说破。

## 硬规则（都有门）

1. **时长预算先于一切（S7）。** 单集估算秒数必须落在 `episodeSeconds` 区间里。写超先砍动作，写短补冲突。
2. **钩子在前 3 拍（S9）。** `hookBeat` 指向兑现开场钩子的那一拍，必须在全集前 3 拍内。钩子要在运动中给：抱着皮箱在雾里跑，好；静物特写一闪，差。
3. **单句一口气说得完（S10）。** 中文不超过 35 字，英文不超过 25 词。长句拆成两句，中间插一拍动作或对方的反应。
4. **每场至少一拍动作（S11）。** 三句台词之间没有画面，观众就只是在听广播。
5. **动作里不夹台词（S12）。** 动作节拍出现引号对白，就拆成单独的 dialogue 节拍。
6. **说话人必须在场（S6）。** 电话、短信、心声用 `voiceover`。

## 手感规则（只有警告或没有门，但决定好不好看）

- **旁白省着用（S13）。** 一集最多三条，用在「表面平静、心里翻江倒海」的错位时刻。
- **台词短，动作密（S14）。** 连续四句以上台词就该插动作或反应。
- **结尾最后一拍是悬念。** 一句没说完的话、一个没解释的动作、一声来历不明的响。门查不了，自己查。
- **谁的话像谁。** 写之前读人物 `summary`；盖住名字也认得出是谁在说话。

## 常见动作

这部戏最终由视频模型来演，它只会演它见过很多次的动作。

| 写法 | 例子 | 生成结果 |
| --- | --- | --- |
| 差：精确的物理交互 | 他伸手一挡，药瓶擦着指尖落进抽屉 | 多物体交互，容易崩 |
| 好：常见动作 | 他把药瓶放进抽屉，关上 | 拿、放、关，都是常见动作 |

放心写：走进来、坐下、递东西、点头、回头、站起来、打电话、推门。
改写或删掉：微表情（睫毛颤）、以寸计的位移、比喻性画面（像被雾攥住的茧）、多个物体同时交互。

戏剧信息靠常见动作的组合和时机给，不靠动作本身有多精巧。

## 修改纪律

- **改一拍，连读三拍。** 改完把前后各一拍连起来读，查三样：人物位置、道具在谁手里、谁在场。
- **改动作，记得下游。** 动作改了，分镜的画面、声音、分镜图都要跟着动。

## 常见病

| 病 | 症状 | 治法 |
| --- | --- | --- |
| 广播剧 | 整场只有台词 | 每两三句台词插一拍动作 |
| 文学病 | 动作写成美文 | 换成常见动作 |
| 开场死画面 | 第一拍是静物特写 | 同一个画面换成运动中给 |
| 空间跳变 | 上一拍在门口，下一拍已在后库 | 补一拍走过去 |
| 注水 | 寒暄、让茶占了半集 | 删；每一拍要么推进剧情，要么翻转关系 |
| 全知病 | 台词把信息说尽 | 信息藏进动作和 emotion，台词只说三分 |
| 断头戏 | 结尾平收 | 最后一拍换成悬念 |
