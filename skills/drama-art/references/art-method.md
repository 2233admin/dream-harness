# 美术设定：方法

学习来源：shuohao-skills `novel-art`（Apache-2.0）的场景与道具规则（先定年代、锚点可核对、光照状态从剧情反推、空景、禁名字、不写画风）；按本仓契约重写。

## 这是 AI 短剧，不是实拍

场景是要被生成几十次、每次都得长一样的环境资产。每个字段都为一致性服务：

| 字段 | 解决什么 |
| --- | --- |
| `era` | 建筑、家具、器物共用的年代基准；不定它，每个场景各挑一个年代 |
| `anchors` | 观众靠什么认出「又回到这里了」；验收靠什么判断镜头没漂 |
| `states` | 换时段、换天气就是换提示词重新生成，不是现场打灯 |
| 空景 | 场景图里有人，人物一致性就毁了 |

## 年代

全剧一个具体的年代与地域，比如「2020年代中国南方城市」「民国上海」「明代江南」。

不写「古代」「架空」「某朝」「historical」（A3）：这些词在画面上没有对应物，模型只能自己挑。原作是架空设定时，写它像哪个年代。

## 场景

- `purpose` 写设计意图，不写户型：「一排柜台隔开药师和顾客，所有对峙都隔着这块玻璃发生」，而不是「约二十平米」。
- 锚点 3–5 个，可画、可认、可核对：墙上的红色电子钟、门口的铜风铃。「陈旧的氛围」不是锚点。
- 每个锚点的英文 `prompt` 原样写进 `imagePrompt`（A4）。
- 光照状态从剧本反推：这个场景在剧里出现在哪些时段、什么天气，就写哪些状态；用不上的状态是维护负担。
- `imagePrompt` 英文，写明 `empty scene, no people`（A6），`negativePrompt` 禁人、禁手、禁文字。

## 叙事道具

入选的判据在大纲阶段已经定了（它丢了剧情会不会塌）。这里只负责让它每次出现都一样：

- `purpose` 写戏剧功能：「第一集的物证：章是印上去的，不是盖上去的」。
- 锚点经得起特写：1–5 个，比场景锚点更小更细。
- 状态从剧情反推：合上 / 打开，单张 / 一整叠。
- `imagePrompt` 用产品图的写法：主体、材质、锚点、`studio product shot, plain white background`。

## 不写画风

写实、动漫、水墨在出图时统一指定。写进每条提示词只会和当时选的风格打架，换风格还要逐条改。
