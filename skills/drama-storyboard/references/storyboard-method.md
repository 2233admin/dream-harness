# 分镜：方法

学习来源：shuohao-skills `novel-storyboard`（Apache-2.0）的分段切镜、节拍认领、首帧点名与正文通用身份、导演运镜手感；cheng-yi-jing-skill（MIT）Shot Card 的「先锁剧本事实，再写画面」。按本仓契约重写，不绑定任何一个视频模型。

## 三层结构

| 层 | 是什么 | 约束 |
| --- | --- | --- |
| 集 | 剧本的一集 | 可以分批分镜（K13 警告） |
| 段 `segment` | 一次视频生成调用 | 不跨场次；总长不超过 15 秒（K5） |
| 镜 `shot` | 段内的一次剪切 | 1.5–8 秒（K5），围着 3 秒打 |

## 节拍认领是地基

每镜写 `beats: [起, 止]`，是这一场节拍的连续区间，从 0 数。一场的所有节拍必须按顺序被认领，不重不漏（K4）。剧本改了，重跑校验，失效的镜头会被点名。

认领了台词的镜头，秒数必须装得下这些台词（K6）。4.4 秒的台词给 5 秒的镜头。

## 每镜的字段

| 字段 | 写什么 |
| --- | --- |
| `size` | 景别：extreme-wide / wide / full / medium / medium-close / close-up / extreme-close-up / insert |
| `angle` | 角度：eye-level / high / low / overhead / dutch / over-shoulder / pov |
| `movement` | 运镜，一镜只有一个：static / push-in / pull-out / pan / tilt / track / follow / handheld / crane / orbit |
| `subjects` | 画面里的人物、服装（可选）和这几秒里的动作 |
| `locationState` | 用 art.json 里哪个光照状态 |
| `props` | 画面里出现的叙事道具 |
| `frame` | 首帧画面：这一镜开始那一瞬的构图，**直呼角色名**（K10） |
| `body` | 镜头正文：这几秒发生了什么，**不写人名**，用通用身份（K11） |
| `sound` | 声音：环境声、动作声；台词由编译器从节拍里取，不重复写 |

为什么首帧要点名、正文不能点名：首帧是和角色参考图一起出图的，名字是指向某张参考图的地址；视频模型的官方提示词规范要求正文用通用身份（「一名穿白大褂的年轻女药师」），姓名只出现在台词原文里。

## 镜头正文怎么写

- **动作能在这几秒内做完。** 沿用剧本的常见动作原则：推门、递东西、抬头、转身；不写精确的物理交互和微表情。
- **肢体加程度。** 缓慢抬手、快速转头、微微低头。
- **情绪外化成身体。** 紧张是频繁看表、眼神躲闪；愤怒是双拳握紧、下颌绷紧。不写「很生气」。
- **人物位置和首帧一致。** 首帧是这一镜开始的那一瞬，正文从那一瞬往后写。
- **一镜一个运镜。** 推完再摇，模型只会挑一个做。

## 导演手感（不设门，但决定像不像专业分镜）

- **3 秒一切是短剧的呼吸。** 长短相间，别一路 5 秒。
- **开场先给运动的主体。** 每集第一镜要有人在动（K12 警告第一镜没有人物），然后再定场，再给关键局部特写。
- **对话切正反打。** 问话给问话人，答话给答话人；信息量大的那句给更近的景别。
- **关键动作独立成镜。** 「拇指蹭过红章」值得单独一个 2–4 秒的特写（insert）。
- **反应镜头是免费的戏。** 一句重台词之后，切听者的脸 2–3 秒。旁白盖在特写或空镜上，省口型。
- **动接动。** 上一镜结尾的动势接下一镜开头的动势，切点选在动作中间。

## 段的走位

每段写 `blocking`：开场谁在画面左、谁在右，朝向哪里，相距多远。同一段内多镜共享这个空间关系，一次生成才能前后连贯。
