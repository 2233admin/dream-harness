# 分集大纲：方法

学习来源：shuohao-skills `novel-outline`（Apache-2.0）的分集三栏与爽点间隔规则；按本仓契约重写。

## 每集写什么

| 字段 | 写什么 |
| --- | --- |
| `synopsis` | 这一集发生了什么。叙述体，不写台词。 |
| `hook.opening` | 开场第一个抓人的具体画面或问题。剧本会把它落成全集前 3 拍之一。 |
| `hook.cliffhanger` | 结尾停在哪里，让人点下一集的那个问题。只有最后一集可以留空（O6）。 |
| `payoffs` | 这一集兑现的爽点，每条一个类型加一句话。 |
| `characters` / `locations` / `props` | 这一集用到的清单 id。剧本会对账（S8）。 |

## 爽点类型

| kind | 含义 |
| --- | --- |
| `reversal` | 反转：局面突然翻过来 |
| `face-slap` | 打脸：被看低的人当场证明自己 |
| `reveal` | 揭露：秘密或真相曝光 |
| `romance` | 甜：感情推进 |
| `revenge` | 复仇：恶有恶报 |
| `comedy` | 笑点 |
| `other` | 其他，`text` 里写清楚 |

爽点要能在戏里演出来：写「打脸」，这一集的梗概里就得有被看低、再当场证明的过程。

规则：连续不超过 3 集没有爽点（O9，`project.rules.maxPayoffGap` 可调）。

## 钩子

- 开场钩子要具体到一个画面：「同一个少年，同一个签名，这个月第三次」，不是「悬念拉满」。
- 结尾钩子停在问题刚出现、答案还没给的那一刻。上一集的结尾钩子，下一集开场要接住（接住不等于立刻解开）。

## 清单

- **人物**：`role` 分 protagonist（主角，至少一个，O7）、antagonist、supporting、extra。没出现在任何一集的人物会有警告（O8）。
- **场景**：AI 换景不花钱，但观众每换一次景都要重新建立空间感；一集两分钟内不超过三四个场景。
- **叙事道具**：判据是它丢了剧情会不会塌。会塌才收，不超过 8 件（O15）；`narrative: false` 的道具只做登记，不进爽点。
