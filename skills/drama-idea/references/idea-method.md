# 从一句话到故事设定：方法

学习来源：oh-story-claudecode（MIT）「套路是确定性的情绪满足」的选材思路；按短剧篇幅重写。

## 一句话怎么写

一句话 = 谁 + 想要什么 + 被什么挡住 + 观众最想看到的那一刻。

- 好：夜班药师发现老板用预盖章的空白处方倒卖止咳水，她要在交班前拿到证据。
- 差：一个关于正义与良知的都市故事。（没有人、没有欲望、没有阻碍）

## 卖点

卖点是观众点开第一集、并且愿意看到最后一集的理由。写成两层：

1. **情绪承诺**：这部剧让观众反复得到哪一种满足（被低估者翻盘、误会解开、恶人现形）。这是题材的「套路」，套路就是确定的情绪满足，不是贬义。
2. **具体抓手**：别的同题材剧没有的那个东西（一个职业细节、一件道具、一个反常设定）。

## 主要人物

每个主要人物一行：名字、身份、欲望、弱点。主角的欲望必须能在剧里被看见（拿到证据、保住铺子），不能只是心理状态（变得勇敢）。

短剧人少：主角组 1–3 人，对手 1 人起，配角按需。每多一个有名字的角色，下游就多一套定妆、参考图和音色。

## 核心冲突

一句话写清：主角要 A，对手要 B，A 和 B 不能同时成立。再写一句：冲突为什么必须在这部剧的时间内解决（期限、倒计时、一次性的机会）。

## 梗概

- 每集一条，按 `1.`、`2.` 编号。
- 每条写：这一集发生的事 + 结尾停在哪里。
- 每集至少一个爽点（反转、打脸、揭露、甜、复仇、笑点）；连续三集没有爽点，观众就走了。
- 最后一集收主线；其余每集结尾都要留一个让人点下一集的问题。

## 三个方向怎么拉开

给作者挑的三个方向，至少在一个维度上明显不同：

| 维度 | 例子 |
| --- | --- |
| 题材 | 悬疑 / 职场爽 / 甜宠 |
| 主角 | 同一事件，换成受害者、旁观者或加害者的视角 |
| 冲突来源 | 外部对手 / 制度与规则 / 主角自己的秘密 |

方向卡格式：

```
方向 A：<一句话>
卖点：<情绪承诺> + <具体抓手>
主角：<欲望> / <阻碍>
第一集钩子：<结尾停在哪一刻>
```
